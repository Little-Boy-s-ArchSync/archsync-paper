## Work that actually closes the main scientific gaps

The existing EXTERNAL-BASELINE-PROTOCOL.md remains Proposed - not executed.
This audit does not bypass its pre-execution approval or silently revise a
frozen protocol. The withdrawn D1 dependency-cruiser scratch comparison is not
reintroduced.

1. Before viewing predictions, approve the target population, repository
   selection, independent units, minimum useful effect/precision and sampling
   rationale. Freeze real repository URLs, licenses, full SHAs and development/
   holdout lineage exclusions. Do not select projects because ArchSync works.
2. Establish a nonempty semantically identical comparison unit. Module imports
   are not remote HTTP/database relationships. Reject an incompatible comparator,
   or develop/validate a separate adapter on non-holdout data before selection.
3. Have separate reviewers label the full declared source scope without tool
   predictions, including relationships the tool might miss. Preserve raw labels,
   unresolved cases, disagreements and the permitted reconciliation. Team-member
   annotations still require disclosure of developer involvement.
4. Freeze tools, configurations, scoring and failure handling, then run both on
   the same eligible inputs. Preserve stdout/stderr, exits, raw outputs, runtimes,
   environment, hashes and all failed/unsupported cases.
5. Report errors and coverage per repository, then justified pooled estimates.
   Treat repeated runs and many edges in one repo as clustered, not independent.
   Use the approved statistical plan; add no confidence intervals to a
   convenience sample merely to make the paper appear stronger.
6. For an integration-value claim, use a predeclared ablation (e.g. introduced
   findings versus a full-current-findings gate) and measured false-block/review
   burden on independent history. Otherwise keep the claim descriptive.

Required team inputs: approved holdout/protocol, confirmed independent-label
reviewers, a valid comparator or adapter decision, and real execution outputs.
These are not replaced by this edit, AI-generated labels, passing CI or a
larger synthetic test suite. Submission suitability cannot be guaranteed.
