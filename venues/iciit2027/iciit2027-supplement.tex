\begin{abstract}
This supplement supplies operational detail for ArchSync's controlled implementation verification and technical reliability checks. It identifies the historical and current artifact scopes, finite oracle construction, mutation procedure, retained extraction and cache failures, and proposed repository follow-up. These details accompany the main manuscript's reported development evidence.
\end{abstract}
