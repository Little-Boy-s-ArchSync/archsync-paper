# Canonical paper diagrams

Fig-1.tex and Fig-2.tex are the canonical vector sources for the integrated IEEE
manuscript. Compile them with Tectonic or pdflatex in this directory to regenerate
the PDF figures. They use high-contrast text on light fills for print legibility.
The retained SVG files are historical draw.io exports from 8e7098b and are not the
source of the integrated PDF figures. Both length variants include the same PDFs.
