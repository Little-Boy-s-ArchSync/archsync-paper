# Test-only canonical SLR candidate inputs

These two documents are exact byte snapshots of the public candidate inputs at
commit `7cdfc6ddfd56904122d0eca8648e164468e97c71`; `provenance.json` records their
source paths and SHA-256 values. They are unit-test inputs, not live protocol,
decision, approval or research evidence. Do not use this directory to authorize
search, review, signing or freeze.

Candidate contract tests read these snapshots so a legitimate transition of the
live repository to protocol 1.0.0 does not change the starting state of tests.
The snapshots are never generated by editing frozen metadata back to candidate
values. Explicit frozen test cases start from this fixed candidate and retain
their own test review and sentinel artifacts. Tests of the actual CLI still read
the live protocol and its actual review/evidence files, and assert the exact
supported candidate or frozen result.

Other research documents and the manuscript remain live integration inputs.
Changes to this canonical fixture require a separately reviewed test-contract
revision; freezing the live protocol does not update it.
