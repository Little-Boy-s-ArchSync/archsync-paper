An exploratory external-tool inventory used dependency-cruiser~18.3.0 and pinned ArchSync Guardian~0.3.3 artifacts on the D1 baseline and its 20 isolated patches. Inputs, configuration and the corrected execution script were committed before the valid run; all 42 tool executions completed. Across the 20 patched repositories, dependency-cruiser reported 54 import-dependency instances (50 unresolved package references and four resolved local imports), while Guardian reported 108 service-relationship instances. These totals use different semantic units: D1 labels HTTP, PostgreSQL, Redis and AMQP relationships, whereas dependency-cruiser inventories module imports and Guardian does not expose those imports as architecture edges. Consequently, the shared labeled subset is empty and comparative precision, recall and F1 are not estimable. This executed capability check uses co-developed regression data and establishes neither an external accuracy baseline nor tool superiority; unsupported service relationships are not counted as comparator false negatives.
